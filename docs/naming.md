# Gravity by Noveum

Gravity is the product name selected by the project owner. Use “Gravity by Noveum” in documentation and “Gravity · CRM by Noveum” in application metadata. The local checkout remains `noveum-crm`; publication and GitHub repository creation are separate release steps.

Relay and Novastave were earlier candidates and are superseded. No claim of exclusive name ownership, domain availability, trademark clearance, or guaranteed SEO ranking is made. The authenticated app remains excluded from search indexing. A future public landing page should describe the product as an open-source CRM for multi-product outreach and link to Noveum.
